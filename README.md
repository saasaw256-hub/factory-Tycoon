# Factory Tycoon

A polished 2D factory-management browser game built with vanilla HTML, CSS and JavaScript. No build tools or dependencies are required.

## Play locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Your progress saves automatically in that browser using local storage.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository** named `factory-tycoon` (or another name you prefer).
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md`. Keep them together in the repository's root folder.
4. Select **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Set the branch to `main` and the folder to `/ (root)`, then click **Save**.
8. Wait a minute or two. GitHub will show your published site URL in the Pages section. It will look like:
   `https://YOUR-USERNAME.github.io/factory-tycoon/`

## Gameplay

- **Collect incoming ore:** click the green action or press Space.
- **Smelt ore:** manually convert 10 raw ore into 1 iron ingot. Your smelter also works automatically when you have ore.
- **Sell ingots:** sell your current ingot inventory for cash.
- **Upgrade:** invest in the Smelter, Industrial Press, Auto Packer and Mining Drill.
- **Save:** game progress is saved automatically in the browser on the device you play on.
- **Offline progress:** returning players receive up to two hours of simulated factory production.

## Notes

- This is a static browser game; no server or database is needed.
- The Google Fonts import is optional. If unavailable, the game uses local sans-serif fallbacks.
- Progress is stored per browser/device. It does not automatically sync between devices.
